10. What is BFS?

Answer:
BFS stands for Breadth-First Search. It explores nodes level by level.

Data structure: Queue.

👉 BFS = Queue + Level by Level


---

11. What is DFS?

Answer:
DFS stands for Depth-First Search. It explores as deep as possible before backtracking.

Data structure: Stack.

👉 DFS = Stack + Depth first


---

12. What is the difference between BFS and DFS?

Answer:
BFS uses a Queue and searches level by level, while DFS uses a Stack and searches depth-wise.

Specialized & Advanced Learning Variations

• Super Learner (Stacking Ensemble): Trains a diverse library of candidate algorithms (e.g., Lasso, Random Forest, Neural Net) on the same dataset and uses cross-validation optimization to find the optimal weighted combination that minimizes generalization error.



• Weakly Supervised Learning: Trains on noisy, incomplete, or coarse-grained labels (e.g., bounding boxes instead of pixel masks).



• Active Learning: The model queries a human oracle to label only the most informative or uncertain data points, minimizing labeling costs.



• Transfer Learning: Adapts a model pre-trained on a massive source domain (like ImageNet or Common Crawl) to a new, smaller target domain.



• Multi-Task Learning: Shares representations across multiple related prediction tasks simultaneously to boost generalization on all of them.



• Online / Incremental Learning: Continuously updates model parameters on streaming data without retraining from scratch.
